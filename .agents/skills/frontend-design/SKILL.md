# Frontend Design: Hami Hamrah

Make deliberate, opinionated choices about palette, typography, and layout that are specific to the brief.

## Core Rules
- **Hero is a Thesis:** Open with the most characteristic element (e.g. Mashhad store 20-year history, rotating keywords, live shop window).
- **Typography:** Estedad + DM Mono pairing. Distinct type scale.
- **Micro-interactions:** Smooth animations (`cubic-bezier(0.2, 0.7, 0.3, 1)`), pill hover effects.
- **Copy:** Conversational, authentic Persian copy from the end-user's perspective.
