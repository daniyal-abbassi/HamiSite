# Implementation Plan: وارد کردن هوشمند محصول از دیجی‌کالا (Digikala Product Importer)

- **شاخه/ویژگی:** `022-digikala-product-importer`
- **تاریخ:** ۲۰۲۶-۱۰-۱۰
- **مستند مبنا:** [spec.md](./spec.md)

---

## ۱. خلاصه معماری و رویکرد (Summary)

قابلیت ورود هوشمند محصولات از دیجی‌کالا به منظور تسریع افزودن کالاها به پنل ادمین طراحی شده است. این قابلیت شامل یک موتور ارتباط با سرورهای دیجی‌کالا از سمت سرور Next.js (بدون درگیری کلاینت با محدودیت‌های CORS و با مدیریت خودکار ریدایرکت ۳۰۷ کوکی DigiCDN) و رابط کاربری اختصاصی برای جستجو و ورود مستقیم با لینک در پنل ادمین می‌باشد.
داده‌های استخراج شده مستقیماً به فرمت استاندارد محصولات حامی (`ProductForm`) نگاشت می‌شوند و ادمین می‌تواند قبل از ذخیره نهایی، مشخصات فنی، متون و تصاویر را بازبینی نماید.

---

## ۲. بستر فنی و وابستگی‌ها (Technical Context)

- **محیط اجرایی:** Next.js 15.5.25 App Router, React 19, TypeScript 5
- **امنیت و احراز هویت:** مسیرهای API تحت پوشش `requireAdmin` در `lib/admin-access.ts`
- **کلاینت:** کامپوننت‌های پنل ادمین با استایل تیره/لوکس (Tailwind CSS، Lucide Icons)
- **ارتباط با دیجی‌کالا:** ماژول سرور ساید `lib/digikala.ts` برای اجرای ریکوئست‌های HTTPS با متد Cookie-following
- **بدون وابستگی سنگین:** استفاده از امکانات داخلی Node.js/Next.js بدون نیاز به کتابخانه‌های اضافی اسکرپینگ یا مرورگر هدلس

---

## ۳. برش‌های عمودی و ترتیب پیاده‌سازی (Vertical Slices)

```
[1. ماژول ارتباطی سرور (lib/digikala.ts)]
   │
   ├── [2. اندپوینت‌های API ادمین (/api/admin/importer/digikala/*)]
   │      │
   │      └── [3. کامپوننت مودال جستجو و استخراج (DigikalaImportDialog.tsx)]
   │             │
   │             └── [4. اتصال به لیست محصولات و فرم محصول (ProductsAdminClient & ProductForm)]
```

### برش ۱: سرویس سرور دیجی‌کالا (`lib/digikala.ts`)
- استخراج شناسه محصول از انواع ورودی‌ها (عدد خام، `dkp-12345`، لینک کامل محصول).
- ارسال امن درخواست به `https://api.digikala.com/v1/search/` و `https://api.digikala.com/v2/product/{id}/` همراه با مدیریت ریدایرکت ۳۰۷ کوکی DigiCDN.
- تبدیل خروجی خام به ساختار استاندارد حامی (عنوان، اسلاگ، گالری تصاویر، ویژگی‌های فنی `specs: [{ name, value }]`، برند، توضیحات و سئو).

### برش ۲: اندپوینت‌های مدیریت (`app/api/admin/importer/digikala/...`)
- مسیر `GET /api/admin/importer/digikala/search?q=...&page=...`
- مسیر `GET /api/admin/importer/digikala/product?id=...`
- اعمال گیت احراز هویت و دسترسی ادمین (`requireAdmin`).

### برش ۳: کامپوننت مودال استخراج (`components/admin/products/DigikalaImportModal.tsx`)
- تب جستجو بر اساس کلیدواژه (جستجوی زنده، نمایش تصویر، قیمت، نام کالا و دکمه انتخاب).
- تب ورود مستقیم با پیوند محصول یا کد کالا.
- پیش‌نمایش سریع داده‌های استخراج شده با امکان لود مستقیم در فرم یا ایجاد سریع.

### برش ۴: ادغام با پنل مدیریت کالاها (`ProductsAdminClient` و `ProductForm`)
- افزودن دکمه «وارد کردن از دیجی‌کالا» در بالای صفحه لیست محصولات (`/admin/products`).
- پشتیبانی `ProductForm` از پیش‌پر شدن مقادیر اولیه (Initial Values) هنگام کلیک روی انتقال به فرم.

- **بررسی نوع‌سنجی:** اجرای `npm run typecheck` و اطمینان از سازگاری کامل تایپ‌ها.
- **تست عملکردی روی سرور:** اعتبارسنجی عملیاتی جستجو و واکشی در مرورگر واقعی.
