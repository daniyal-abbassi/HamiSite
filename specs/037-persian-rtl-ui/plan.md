# Implementation Plan: Persian RTL UI Standards Compliance

**Branch**: `037-persian-rtl-ui` | **Date**: 2026-10-14 | **Spec**: [spec.md](spec.md)

---

## 1. Summary

This feature brings the entire Hami codebase into strict compliance with the Persian RTL UI guidelines specified in `https://farsiui.ir/skills/persian-rtl-ui` and `.cursor/skills/persian-rtl-ui/SKILL.md`.

The technical plan focuses on 5 core pillars:
1. **Systematic Logical Property Migration**: Refactoring all remaining physical directional utilities (`ml-`, `mr-`, `pl-`, `pr-`, `left-`, `right-`, `text-left`, `text-right`, `space-x-*`) to CSS logical properties (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`, `text-start`, `text-end`, `gap-*`).
2. **Typography & Ligature Preservation**: Removing `tracking-tight` and negative tracking from all Persian headings and copy to ensure seamless character joining in Vazirmatn.
3. **Directional Icon Inversion**: Flipping forward/next chevrons and call-to-action arrows to point left (`ArrowLeft`, `ChevronLeft`) and back arrows to point right (`ArrowRight`, `ChevronRight`) in accordance with RTL reading flow.
4. **Bidi Form Input Hardening**: Adding `dir="ltr"` to passwords, phone numbers, OTPs, IBANs, and Latin SKUs while maintaining RTL labels.
5. **Persian Number & Currency Normalization**: Ensuring prices use Persian numerals followed by «تومان» and tabular numbers align to `text-start`.

## 5. Implementation Phases

- **Phase 1: Setup & Primitives**: Implement `lib/persian-typography.ts` helper and create unit test suite `tests/unit/persian-rtl-ui.test.ts`.
- **Phase 2: Logical Directional Classes**: Refactor all physical classes (`ml-`, `mr-`, `pl-`, `pr-`, `text-left`, `text-right`, `space-x-*`) across `components/` and `app/`.
- **Phase 3: Typography & Letter Ligatures**: Remove `tracking-tight` and negative tracking on Persian headings, labels, and badges across TMA, admin, and storefront.
- **Phase 4: Directional Icon Semantics**: Update forward/backward arrows and pagination chevrons to respect RTL reading direction.
- **Phase 5: Form Fields Bidi Isolation**: Add `dir="ltr"` and `inputMode` to password, phone, card, and code inputs under RTL labels.
- **Phase 6: Quality Gates & Verification**: Run typecheck, unit tests, Next.js build, and Playwright visual check.
