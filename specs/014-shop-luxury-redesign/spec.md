# Shop luxury redesign

User request, 2026-09-30: the approved partners redesign should be extended to the existing shop page.

The shop should read as the same brand: burgundy, champagne, ivory, Estedad, restrained editorial composition. A short hero introduces the catalog; products remain the primary content. Preserve server-rendered catalog data, query contracts, pagination, category destinations, search, sorting, filters, grid/list choice and purchase eligibility. Prices and stock retain their dated source disclosure. No invented inventory, discounts, metrics or availability claims.

Acceptance: responsive layout at 360px and desktop; no horizontal page overflow; visible controls and states on paper; mobile filter sheet stays usable; existing query and product actions continue to work. Shared homepage/product-detail cards should retain their existing appearance.

Scope: /shop page and its presentation components, isolated stylesheet. API, database, catalog data, product detail and shared ProductCard source are outside scope.
