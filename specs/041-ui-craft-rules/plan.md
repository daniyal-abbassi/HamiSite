# Implementation Plan: UI Craft Rules & Quality Enhancement (041-ui-craft-rules)

**Branch**: `041-ui-craft-rules` | **Date**: 2026-10-18 | **Spec**: [spec.md](spec.md)

## Summary

This feature establishes and enforces rigorous UI craft rules across the Hami Hamrah storefront to eliminate AI-generated styling defects (arbitrary Tailwind values, missing touch targets, unreserved media dimensions causing layout shift, inconsistent typography, and generic loading spinners). It includes:
1. Hardening existing storefront views (Header, Product Cards, Cart, Shop Filters) for >= 44×44px touch targets, mobile responsiveness at 360px–390px, and `aspect-ratio` space reservations.
2. Aligning typography to a disciplined ~6-step scale with role-based Persian line heights (1.7–1.9 body, 1.2–1.4 headings, 0 letter-spacing), semantic theme colors, and layout-matched skeleton loaders.
3. Building an automated craft audit scanner (`tools/craft/audit.mjs`) and enshrining the 35-item Done Checklist in repository agent instructions (`AGENTS.md` / `CLAUDE.md`).

## Technical Context

- **Language/Version**: TypeScript 5.x, Node.js >= 20.x, React 19 / Next.js 16 (App Router).
- **Primary Dependencies**: Tailwind CSS, Lucide React (`lucide-react`), Radix UI / shadcn primitives.
- **Storage**: N/A (UI craft rules focus on frontend components, design tokens, and audit tooling).
- **Testing**: Vitest unit test suite (63 suites, 608 tests), `tsc --noEmit`, Playwright visual checks.
- **Target Platform**: Modern web browsers (mobile Chrome/Safari on iOS & Android, desktop).
- **Project Type**: E-commerce web application with rich Persian RTL storefront.
- **Performance Goals**: Cumulative Layout Shift (CLS) <= 0.05, 60fps transitions, audit scan < 2s.
- **Constraints**: Touch targets >= 44×44px, no arbitrary Tailwind pixel values, strict Persian typography rules (0 letter spacing, no uppercase), zero regression across existing 608 tests.
- **Scale/Scope**: All storefront user-facing views under `app/` and `components/`.

## Constitution Check

- **Principle I: Honest Interface**: PASSED. UI craft enforces honest layout, banning fake placeholder stats, artificial empty space, and lorem ipsum text.
- **Principle II: Persian RTL by Default**: PASSED. All typography and directional icons adhere to Persian RTL rules; logical CSS properties (`start`/`end`, `ms`/`me`, `ps`/`pe`) preserved.
- **Principle III: Database-backed Storefront & Back Office**: PASSED. No schema or database alterations required; purely frontend and tooling craft enhancements.
- **Principle IV: Design Is Open — Luxury Is the Quality Bar**: PASSED. Directly implements the core tenets of Principle IV ("million-dollar luxury experience") by replacing arbitrary, AI-looking template styling with disciplined proportions, whitespace rhythm, and refined micro-interactions.
